# Support

Start with [Getting started](docs/GETTING_STARTED.md) and [Troubleshooting](docs/TROUBLESHOOTING.md). For unresolved issues, use the repository bug-report template. Feature requests are welcome through Issues. For vulnerabilities, follow [Security](SECURITY.md).

TouchFlow is an early community project without guaranteed support or response times. Windows x64 is the current distribution target. Do not include codes, tokens, private text or personal network details in public reports.
