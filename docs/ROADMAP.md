# Roadmap

## Current alpha

Local phone controls and a Windows companion with explicit pairing and revocation. Portable x64 distribution. Core automated protocol tests and packaged startup checks. Broad physical-device validation is pending.

## Next priorities

1. Validate real iOS Safari and Android Chrome sessions against Windows 10/11; record latency, disconnect recovery and keyboard-layout behavior.
2. Design authenticated encrypted transport with usable certificate provisioning and protection against local network interception.
3. Improve address selection, QR pairing, accessibility, connection diagnostics and multi-touch behavior.
4. Add signed Windows builds, a reviewed installer and a clear update strategy.
5. Evaluate additional desktop platforms and advanced gestures after the Windows core is dependable.

No delivery dates are promised. Proposals and bug reports belong in Issues. Remote desktop video, unattended internet control and cloud accounts are outside the current scope.
