# Windows companion

For users, start with [Getting started](../docs/GETTING_STARTED.md). Download the portable release to run without installing Python. From source, use `python companion/touchflow.py` or the root Windows launcher.

For implementation details see [Architecture](../docs/ARCHITECTURE.md), [Development](../docs/DEVELOPMENT.md) and [Security](../SECURITY.md).

This alpha uses plain HTTP on port 8765 and is intended only for trusted private networks. It requires desktop approval, supports one phone and cannot control administrator apps or security screens.
