# Code of conduct

Be respectful, constructive and welcoming. Discuss ideas and code without personal attacks. Harassment, discrimination, threats, doxxing and sharing private information are unacceptable in issues, discussions and pull requests.

Maintainers may edit or remove content, close threads, or restrict participation to protect contributors and productive collaboration. Enforcement should be proportionate and consistent.

To raise a conduct concern, contact the maintainer through an available private GitHub channel. If one is unavailable, request a private channel in an issue without naming people or disclosing private details. Do not use public issues to post personal information.
